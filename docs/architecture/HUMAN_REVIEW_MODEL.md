# Human review model

Human review is a durable task, not an informal spreadsheet side channel. A
review item exposes source evidence, proposed artifact, validator findings, and
lineage. A reviewer may accept, edit, reject, or request repair with structured
feedback.

Edits create a new artifact linked to the proposal; they never overwrite it.
Rejection reopens only affected downstream tasks. Changes to shared policies,
release criteria, or skills require a separately recorded approval. Regulated
facts require domain review, and language-dependent behavior requires a capable
native-language reviewer.
